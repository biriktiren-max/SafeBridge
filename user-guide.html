SafeBridge Global — User Guide

Non-custodial, structured escrow protocol operating on Polygon Mainnet.

🚀 Key Features

  • Supported Tokens: POL, USDT, USDT.e, and PAXG
  • Security Mechanics: Password-protected release & time-locked refund triggers
  • Transparent Fee: 1% sender fee deducted before net amount lock
  • DashView: Real-time on-chain verification & event tracking

📖 Step-by-Step Instructions

1. Connect Wallet

Ensure your Web3 wallet (MetaMask, Coinbase Wallet, etc.) is connected and switched to Polygon Mainnet.

2. Create Escrow Vault

  • Select the asset (POL, USDT, USDT.e, or PAXG) and enter the amount.
  • Review the 1% Sender Fee preview.
  • Set a Time Lock duration (determines when refund logic becomes active).
  • Set a Secret Password. (Share this password with the recipient off-chain).
  • Confirm and submit the transaction.

3. Release or Refund

  • Recipient Enter Vault ID + Secret Password to claim the locked net amount.
  • Sender If the Time Lock expires without release, trigger the Refund action to reclaim funds.

🔒 Security Notice

SafeBridge Global operates entirely via non-custodial smart contracts. Protocol administrators never have access to your locked assets or secret passwords.
