SafeBridge Global — User Guide

Non-custodial, structured escrow protocol operating on Polygon Mainnet.

Key Features

  • Supported Tokens: POL, USDT, USDT.e, and PAXG
  • Security Mechanics: Password-protected release and time-locked refund triggers
  • Transparent Fee: 0.25% sender fee deducted before the net amount is locked
  • DashView: Real-time on-chain verification and event tracking

Step-by-Step Instructions

1. Connect Wallet

Ensure your Web3 wallet (MetaMask, Coinbase Wallet, etc.) is connected and switched to Polygon Mainnet.

2. Create Escrow Vault

  • Select the asset (POL, USDT, USDT.e, or PAXG) and enter the amount.
  • Review the 0.25% sender fee preview.
  • Set a time lock duration. Refund becomes available when it expires.
  • Set a secret password. (Share this password with the recipient off-chain.)
  • Confirm and submit the transaction.

3. Release or Refund

  • Recipient Enter the vault ID and secret password to claim the locked net amount.
  • Sender If the time lock expires without a release, use Refund to reclaim the funds.

Security Notice

SafeBridge Global operates entirely through non-custodial smart contracts. Protocol administrators never have access to your locked assets or secret passwords.
